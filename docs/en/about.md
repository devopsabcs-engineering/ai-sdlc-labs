# About

## What this is

AI-SDLC Labs is a set of hands-on, bilingual (English and French) labs. They teach the full software lifecycle with AI agents: idea, plan, build, test, human sign-off, deploy. The agents come from the open-source [ai-team-sdlc](https://github.com/devopsabcs-engineering/ai-team-sdlc) plugin for GitHub Copilot.

## Who it is for

Developers, architects, product people and team leads who use Windows, PowerShell and VS Code, and who want to see how quality gates and a human sign-off keep AI-built software trustworthy.

## The two repositories

* [ai-sdlc-labs](https://github.com/devopsabcs-engineering/ai-sdlc-labs): this site, the scripts and the screenshots.
* [ai-sdlc-labs-pinch](https://github.com/devopsabcs-engineering/ai-sdlc-labs-pinch): the reference app, with a checkpoint tag per lab.

## Contribute and translate

Every English page has a French twin with the same file name, the same heading structure and the same images. Use the [Glossary](glossary.md) for terms, give every image alt text in both languages, and run the checks locally before you open a pull request. The repository README explains the commands.
