## Learning objectives

By the end of this lab, you will be able to:

* Run the product owner and architect agents to get a PRD and a technical specification.
* Read the architecture decision records (ADRs) and the acceptance criteria.
* Recognize a `spec-review` failure caused by a requirement that silently disappeared from the PRD.
* Trace every requirement from the brief to the PRD.
