# À propos

## De quoi il s'agit

Ateliers AI-SDLC est un ensemble d'ateliers pratiques et bilingues (français et anglais). Ils enseignent tout le cycle de vie logiciel avec des agents d'IA : idée, planification, construction, tests, approbation humaine, déploiement. Les agents proviennent du plugin libre [ai-team-sdlc](https://github.com/devopsabcs-engineering/ai-team-sdlc) pour GitHub Copilot.

## À qui ils s'adressent

Aux développeuses et développeurs, aux architectes, aux personnes qui travaillent en produit et aux chefs d'équipe qui utilisent Windows, PowerShell et VS Code, et qui veulent voir comment les passerelles de qualité et une approbation humaine rendent fiables les logiciels construits par l'IA.

## Les deux dépôts

* [ai-sdlc-labs](https://github.com/devopsabcs-engineering/ai-sdlc-labs) : ce site, les scripts et les captures d'écran.
* [ai-sdlc-labs-pinch](https://github.com/devopsabcs-engineering/ai-sdlc-labs-pinch) : l'application de référence, avec une étiquette de point de contrôle par atelier.

## Contribuer et traduire

Chaque page anglaise a son jumeau français, avec le même nom de fichier, la même structure de titres et les mêmes images. Servez-vous du [glossaire](glossary.md) pour la terminologie, donnez un texte de remplacement à chaque image dans les deux langues et exécutez les vérifications localement avant d'ouvrir une demande de tirage. Le fichier README du dépôt explique les commandes.
