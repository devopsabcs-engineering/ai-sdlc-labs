## Objectifs d'apprentissage

À la fin de cet atelier, vous serez en mesure de :

* Lancer la compétence `ait-deploy` uniquement après l'approbation.
* Configurer GitHub Pages avec un flux de travail GitHub Actions et un environnement.
* Expliquer et vérifier les passerelles `pre-deploy`, `smoke` et `rollback-ready`.
* Revenir à la version précédente.
